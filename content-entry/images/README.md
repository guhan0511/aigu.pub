# 图片资源更新入口

本目录是**唯一**的图片资源提交/更新入口。所有新增图片素材都应放在这里对应的分类子目录中，不要直接丢进根目录或 `images/` 网站资源目录。

## 分类子目录

| 子目录 | 用途 | 现有图片 |
| --- | --- | --- |
| `profile/` | 个人头像 / 形象照 | `profile.jpg`、`professional_profile.jpg` |
| `qrcode/` | 二维码类图片 | `Elys_QRcode.png` |
| `ui-screenshots/` | 产品 / 作品 UI 截图 | `Elys.PNG`、`ElysUI.png` |
| `decorative/` | 装饰性设计素材（背景、矢量图形等） | `collage-bg.svg`、`collage-hero.svg`、`deco-geo.svg` |
| `social/` | 社交账号展示图 | `Ins.JPG`、`Wechat.JPG` |

需要新分类时（如 `travel/` 旅行照片、`work/` 工作现场图、`reading/` 阅读相关），直接新建子目录并补充上表。

## 图片格式与尺寸要求

- 格式：照片类优先 `.jpg`/`.jpeg`；带透明背景或截图优先 `.png`；矢量图形使用 `.svg`
- 文件大小：单张建议不超过 2MB，照片类可压缩后再上传（保证网站加载速度）
- 尺寸建议：
  - 头像类（`profile/`）：正方形或 3:4，建议不小于 800×800px
  - 二维码（`qrcode/`）：正方形，建议不小于 400×400px，背景干净无遮挡
  - UI 截图（`ui-screenshots/`）：保持原始分辨率，避免二次压缩失真
  - 装饰素材（`decorative/`）：矢量图优先用 SVG，避免位图放大模糊

## 命名规则

- 使用英文 + 连字符或驼峰，避免空格：`travel-paris-01.jpg`、`qrcode-wechat.png`
- 同一主题多张图片按序号结尾：`-01`、`-02`
- 避免使用中文文件名（跨系统兼容性问题），新上传图片建议统一改为英文命名

## 更新流程

1. 确认图片用途，放入对应分类子目录（无合适分类则新建）
2. 按命名规则重命名后再放入目录
3. 若该图片用于某篇 md 文档，在文档的 **[图片needed]** 标注处注明对应文件名，方便关联查找
4. 若图片最终需要在网站页面中展示，由维护者从本目录挑选、优化后手动复制到仓库根目录的 `images/`，并在对应 html/css 中添加引用（本目录图片不会被网站自动加载）

## 注意事项

- 本目录与根目录 `images/`（网站实际使用的图片资源）是两套用途：本目录是**素材入口/待审核区**，`images/` 是**网站正式引用的资源**，两者不要混用
- 请勿直接修改或删除根目录 `images/` 中正在被网站引用的文件
